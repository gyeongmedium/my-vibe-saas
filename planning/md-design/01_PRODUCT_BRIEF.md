# Product Brief

## 1. Product Summary
이 서비스는 대학생이 시험 기간에 시간 관리, 시험 범위 관리, 과제 관리를 잊지 않고 수행하도록 돕는다.

## 2. Problem

시험기간에 바쁘기 때문에 밀린 올라인 강의를 언제까지 들어야하는지 잊을 수 있고, 시험을 봐야 할 과목이 많고 범위도 넓기 때문에 몇일 까지 얼마나 공부할지 배분을 하기 어렵다. 그리고 과제도 언제까지 해야하는지 잊는 문제가 발생한다. 시험기간에는 집중력이 안 좋아진다는 문제가 있다.

## 3. Target User

- 주요 사용자: 대학생
- 사용 상황: 중간고사, 기말고사 기간
- 사용자의 기술 수준: 보통
- 사용자가 기대하는 결과: 시험기간에 과제와 해야할 일을 마감기한까지 완료할 수 있게 챙겨주고, 시험 봐야 할 과목 공부 범위를 입력하면 언제까지 얼마나 해야지 알려준다.

## 4. Core Value

사용하기 쉽고, 귀여운 UI, 시험기간에 도움이 되는 서비스

## 5. MVP Scope

이번 MVP에 포함할 것:

- 과제, 온라인 강의 마감기한
- 시험 범위를 입력하면 몇 일까지 얼마나 공부해야하는지 배분해줌
- 시험기간에는 공부가 집중이 안되고 지루하기 때문에 캐릭터와 함께 공부하는 기능

## 6. Non-goals

이번 MVP에서 제외할 것:

- 로그인
- 결제
- 실시간 협업
- 대용량 파일 업로드
- 다중 외부 API 연동
- 복잡한 관리자 권한

## 7. Success Criteria

- 사용자는 핵심 기능을 1분 안에 사용할 수 있다.
- 3회차 종료 시 브라우저에서 기본 흐름을 확인할 수 있다.
- 4회차에서 핵심 흐름을 Playwright 테스트로 검증할 수 있다.
- 최종 결과물은 배포 가능한 형태여야 한다.
